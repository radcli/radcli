Welcome to radcli Pages.

A modern RADIUS client library was missing: one with asynchronous request handling for event-driven applications, RFC 5176 Dynamic Authorization (CoA/Disconnect) support, and native handling of modern RADIUS attributes (RFC 8044 types, 64-bit counters). radcli2 fills that gap, alongside a documented API, a test suite, and support for TCP, TLS and DTLS transport.
